# Connected screenshot index

Source and reproduction: [handoff README](README.md). Each image is a raw browser
viewport capture; long content continues below the viewport. The phone connection
panel is a separate scrolled capture. Use [walkthrough.html](walkthrough.html) for
a captioned replay, or open an individual JPEG at its native dimensions.

The toolbar is retained as capture context. Real viewport resizing drives phone
layout, so the Desktop toggle remains selected. Captions distinguish selectors
from actions that must follow them.
